Instrucciones para Configurar y Ejecutar el Proyecto de Scraping

Este documento describe cómo poner en marcha el script de scraping en tu entorno local.

Requisitos

  • Tener Node.js y `npm` (que viene incluido con Node.js) instalados en tu sistema.

Pasos de Configuración y Ejecución

  1. Crea una carpeta para el proyecto:

    En tu computadora, crea una nueva carpeta donde guardarás los archivos del proyecto. Puedes llamarla como prefieras, por ejemplo, eldorado-scraper.

  2. Crea los archivos necesarios:

    Dentro de la carpeta que creaste (por ejemplo, eldorado-scraper), crea dos archivos nuevos con estos nombres exactos:

    • package.json
    • evaluation_spider.js
  3. Copia el contenido:

    Abre los archivos package.json y evaluation_spider.js con un editor de texto simple (como Notepad, VS Code, Sublime Text, etc.). Pega el contenido correspondiente que te fue proporcionado anteriormente para cada uno de estos archivos. Asegúrate de guardar los cambios después de pegar el contenido.

    (Nota: El contenido de estos archivos te fue dado en respuestas anteriores. Si necesitas que los repita, por favor avísame).

  4. Abre la Terminal o Símbolo del Sistema:

    Abre la aplicación de Terminal (en sistemas operativos como macOS o Linux) o el Símbolo del sistema / PowerShell (en sistemas operativos Windows).

  5. Navega a la carpeta del proyecto:

    Usa el comando cd (change directory) para moverte al directorio donde guardaste la carpeta del proyecto. Por ejemplo, si la creaste directamente en tu carpeta de usuario y la llamaste eldorado-scraper, el comando sería:

    cd eldorado-scraper

    Presiona Enter.

  6. Instala las dependencias:

    Una vez que la terminal esté ubicada dentro de la carpeta de tu proyecto, ejecuta el siguiente comando:

    npm install

    Presiona Enter. Este comando lee el archivo package.json y descarga las librerías axios y cheerio necesarias para que el script funcione. Esto creará una nueva carpeta llamada node_modules dentro de tu proyecto.

  7. Ejecuta el script:

    Finalmente, para iniciar el script evaluation_spider.js, usa el comando:

    npm start

    Presiona Enter. Este comando utiliza el script de "inicio" definido en el archivo package.json y ejecuta el archivo evaluation_spider.js usando Node.js. Verás la salida del script directamente en la ventana de la terminal.

¡Eso es todo! Con estos pasos, tendrás el entorno básico listo para empezar a añadir la lógica de scraping específica para extraer los datos requeridos por el desafío.
